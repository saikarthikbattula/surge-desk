## 4. `surgedesk/pipeline.py`
CLI: `python -m surgedesk.pipeline --stage {data,embed,classifier,tag,ranker,rank,brief,eval,benchmark} [--event E] [--force] [--stub]`
- `--event` defaults to `config.DEMO_EVENT`. `--stub` ignores `--stage` and runs `stubs.run_stub_pipeline(event, fixture reports)` for `fixture_event`, printing the counts and output dir.
- Each stage prints `[stage] start`, its key numbers, and `[stage] done in Ns`. Any exception → print a one-line diagnosis with the owning agent, then exit code 1.
- `events` = `json.load(config.OUTPUTS / "events.json")` (written by the data stage).

| Stage | Calls |
|---|---|
| data | `data_humaid.build_reports(force=force)`; assert `config.DEMO_EVENT` is in events, else exit 1 with the list of events and "set SURGEDESK_EVENT" |
| embed | `embed.embed_event(e, force=force)` for each event (demo event first) |
| classifier | `tag.train_classifier(config.train_events(events))` |
| tag | `tag.tag_event(e, force=force)` for each event; then `tag.evaluate_classifier(config.DEMO_EVENT)` |
| ranker | `rank.train_ranker(config.train_events(events))` |
| rank | `rank.rank_event(config.DEMO_EVENT, force=force)` |
| brief | read incidents; `snap = rank.pick_demo_snapshot(incidents)`; write `outputs/<demo>/demo_snapshot.txt`; `at = fairness.apply([i for i in incidents if i.snapshot_time == snap], 0.0)`; `brief.brief_incidents(config.DEMO_EVENT, at, force=force)` |
| eval | `evaluate.run_all(config.DEMO_EVENT)` |
| benchmark | `benchmark.run_all(config.DEMO_EVENT)` |

**dashboard layout:**
- Header row: event name, snapshot dropdown (default `demo_snapshot`), λ slider (0 to 1, step 0.25), reviewer text box, counts: "reports so far / actionable / open incidents / shown".
- Banner (always visible): **"Recommendations only. A human makes every dispatch decision."**
- Cards for the top 10 by `rank_adj` after `fairness.apply(incidents_at_snapshot, lam)`; moving the slider re-renders instantly from stored scores (no model calls). Each card:
  - rank_adj, and the change vs λ=0 (e.g. "▲2"); score and adjusted score; n_reports; place, county, SVI (or "SVI unknown" badge)
  - "Why it ranks here": top `shap_top` entries as small text bars with `FEATURE_PLAIN` names, sign shown

- If `ipywidgets` fails to render, the notebook falls back to `IPython.display.HTML(render_html(...))`.

**live_replay** (the first 20 seconds of the video demo): starts at `replay.busiest_window_start(reports)`, uses `replay.iter_batches(reports, speed, start, duration_s)`, `tag.Tagger(event).tag_batch(batch)` (live embedding), `group.GroupState(event).add(...)`, and every batch `rank.rank_now(state, now, ranker, svi_lookup)` with `now` = last report time in the batch. Displays an HTML table of the current top 10 (rank, place, n_reports, score, top reason) that updates in place, plus counters: reports in, actionable, open incidents, last batch latency (ms) and running p95. Footer text: "Replay of real {event} tweets at {speed}x (1x = 12x real time)". Never pretends to be live real-world data.

## 6. `surgedesk/evaluate.py`
All outputs go to `outputs/<event>/` (plots in `outputs/<event>/plots/`). Every eval function and `run_all` also accept `src_dir: Path | None = None` (default `config.event_dir(event)`), reading and writing there, so tests can run on a temp copy of the fixtures. Every function returns a dict and also writes its own CSV/JSON. Missing inputs → the function returns `{"status": "skipped", "reason": ...}` and run_all continues.

```python
def make_label_sheet(event=config.DEMO_EVENT, n=config.LABEL_SAMPLE_N, n_actionable=config.LABEL_SAMPLE_ACTIONABLE,

```
**Exact metric definitions**
- **Extraction** (needs `data/labels/hand_labels.csv` filled by humans + Agent 3's `extraction_preds.jsonl`): per field, a prediction *matches* if both are empty/null, or if ≥ 50% of the hand label's `content_words` appear in the predicted value's `content_words`. Report per field: match_rate, null_agreement (both null / hand null), predicted_non_null_rate, grounded_rate; plus json_valid_rate (`timing.ok`), mean seconds per report, n_labeled. Rows with an empty labeler or all-empty fields are skipped. Read every labels CSV with `dtype=str, keep_default_na=False`; if a `report_id` looks like scientific notation (e.g. `9.01746E+17`, a Google Sheets export accident), stop with a clear error telling the human to re-export with the column formatted as plain text.
- **Grouping**: from `group_stats.json` (n_incidents, singleton_share, mean/max size) plus, if `data/labels/purity_labels.csv` exists, purity = share of rows with `same_incident` in {y, yes, 1, true}.
- **Ranking** (per snapshot with ≥ 1 incident whose `urgent_proxy == 1`; methods SurgeDesk λ=0, FIFO, Volume, Keyword): k = min(10, n_incidents); precision@k = urgent among top k / k; recall@k = urgent in top k / urgent at snapshot; NDCG@k with binary relevance (log2 discount). Report the mean over snapshots per method → `ranking_metrics.csv` (per snapshot) and summary means.
- **Time to surface**: for every incident that is ever `urgent_proxy == 1`: for each method, minutes from the incident's `first_seen` to the first snapshot where it is in that method's top 10; never surfaced → censored. Report per method: median minutes (surfaced only), share surfaced → `time_to_surface.csv`. This is the headline real-time metric.
- **Fairness**: `fairness.fairness_table` at the demo snapshot, and the mean over all snapshots → `fairness.csv`; line plot of precision@10 and high-SVI share vs λ.
- **summary.json** keys (exact): `event, measured_on {arch, cores, ram_gb, nnpa_flag}, n_reports, n_actionable, n_incidents, singleton_share, classifier_macro_f1, ranker_dev_auc, ranking {method: {p_at_10, r_at_10, ndcg_at_10}}, time_to_surface {method: {median_min, share_surfaced}}, fairness_demo_snapshot (records), extraction {field: match_rate, ..., json_valid_rate, n_labeled} or {"status": "skipped"}, briefings {n, fields_grounded_share, sentences_accepted_share, fallback_share}, purity or null`.
- **docs/RESULTS.md**: generated tables of all of the above with a first line "Measured on IBM LinuxONE (s390x), 3 vCPU, 8 GB, <timestamp UTC>" (from envcheck; if not s390x, write "Development run, NOT LinuxONE" in bold).
